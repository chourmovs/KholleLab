# Pack visuel académique classique

Les fichiers de ce dossier constituent le pack visuel fourni et **déjà commité**. Les fichiers binaires sont présents dans le dépôt ; aucune génération ni téléversement supplémentaire n’est nécessaire.

- `brand/` : bannière, logos, icônes d’application et favicons ;
- `backgrounds/` : ambiances de salle, texture de tableau et grille discrète ;
- `illustrations/` : professeur, étude et éléments mathématiques ;
- `shapes/` : vagues de transition et accent organique ;
- `patterns/` : motifs de formules et de points ;
- `icons/` : pictogrammes des actions principales du poste de travail ;
- `ui/` : références visuelles pour badges et boutons accessibles.

Les SVG de `ui/` servent de références de style : les contrôles applicatifs restent des éléments HTML sémantiques. Les ressources historiques peuvent rester présentes, mais le code d’exécution utilise le pack classique ci-dessus.
